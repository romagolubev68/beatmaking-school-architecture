Обложки курсов и фото наставников (локальные файлы)
==================================================

1) Курсы (карточки битов в каталоге, на главной, в профиле и т.д.)
   - Папка:   public/images/beats/
   - Имя:     <числовой id курса в базе>.jpg
   - Пример:  курс с id=3  →  файл  public/images/beats/3.jpg
   - Как узнать id: откройте курс по ссылке /courses/3 — число в URL это id.

2) Наставники (страница «Наставники»)
   - Папка:   public/images/mentors/
   - Имя:     <id строки в таблице Mentors>.jpg
   - Пример:  наставник с id=1  →  public/images/mentors/1.jpg

3) Формат
   - Расширение: .jpg (JPEG).
   - Рекомендуемый размер под карточку: курсы ~ 1200×720, наставники ~ 1600×1000
     (соотношение не критично: вёрстка обрезает object-fit: cover).

4) Если файла нет
   - Показывается цветной градиент-заглушка (как раньше).

После добавления файлов закоммитьте их в git и задеплойте — Railway отдаёт всё из папки public.
